# vibe-learn 術語表（GLOSSARY）

> **狀態**：T-010 建立（Claude-B）。內容是「第 1 課交付包附的種子術語表」加上第 1 課整合時整理出來的新術語。第 2、3 課的新術語，由各課的整合（T-014、T-016）補進來。
> **用途**：課文、練習、測驗、圖解，以及給 Gemini 的交付包，術語都以這份為準（`docs/CONTRACT.md` 2.4）。表上沒有的新術語，列在交付檔最後的「新術語」清單，由整合的人決定要不要收錄。

## 寫法規則

1. **第一次出現時**，照表上「第一次出現時的寫法」寫（開發用語保留英文，括號附中文；日常用語不用附英文）。**之後**只用英文或中文其中一種，**全課統一**。
2. 「HTML 屬性」（attribute，例如 `id`、`type`）和「CSS 屬性」（property，例如 `background-color`）是兩個不同的東西；兩個同時出現的時候，一定要寫成「HTML 屬性」「CSS 屬性」，不要只寫「屬性」。
3. 程式碼裡的識別名稱（`textContent`、`addEventListener`、`getElementById`、`padding`…）不翻，照原樣寫在行內程式碼裡；要解釋的話，用一句「照著寫就好，意思是…」帶過。
4. 用「你」稱呼學習者；不要寫「很簡單」「只要」這類讓人覺得自己笨的字眼。
5. 同一個詞全站用同一種寫法：不要在一課寫「資料庫」、另一課寫「數據庫」。
6. 術語要加粗體時，粗體只包住詞本身：寫 `**HTML**（超文本標記語言）管…`，不要寫 `**HTML（超文本標記語言）**管…`。結尾的 `**` 前面是全形括號、後面又緊接中文字時，不會變成粗體，網頁上會直接出現 `**`（`check:content` 會抓；約定 2.4）。

|---|---|---|---|
| HTML | 超文本標記語言 | HTML（超文本標記語言） | 管「有什麼」 |
| CSS | 階層樣式表 | CSS（階層樣式表） | 管「長什麼樣子」 |
| JavaScript | （不翻） | JavaScript（網頁用的程式語言） | 管「按下去會怎樣」 |
| browser | 瀏覽器 | 瀏覽器 | 日常用語，不用附英文 |
| server | 伺服器 | 伺服器（server） | 第 2 課才細講，第 1 課只帶一句 |
| prompt | 提示詞 | 提示詞（prompt） | 給 AI 的指示 |
| preview | 預覽 | 預覽 | 日常用語 |
| source code | 程式碼 | 程式碼 | 不要寫「代碼」「源碼」 |
| error message | 錯誤訊息 | 錯誤訊息 | 日常用語 |
| tag | 標籤 | 標籤（tag） | 例如 `<h2>`。大部分標籤是成對的（有開頭標籤和結尾標籤），少數沒有結尾標籤，例如 `<link>`、`<br>` |
| element | 元素 | 元素（element） | 開頭標籤、中間的內容、結尾標籤合起來 |
| attribute | HTML 屬性 | HTML 屬性（attribute） | 寫在開頭標籤裡的額外設定，例如 `id`、`type`；和 CSS 的「屬性」不同（寫法規則 2） |
| id | id | id | 不翻；元素獨一無二的名字，CSS 和 JavaScript 靠它找到元素 |
| class | class | class | 不翻；元素的分類名稱，例如 `class="card"` |
| selector | 選擇器 | 選擇器（selector） | CSS 裡「先點名要改誰」的那一段，例如 `.card`、`#fav` |
| property | CSS 屬性 | CSS 屬性（property） | 例如 `background-color`、`padding`；和 HTML 的「屬性」不同（寫法規則 2） |
| value | 值 | 值 | CSS 屬性冒號後面的內容，例如 `lightyellow`、`24px` |
| background-color | 背景顏色 | `background-color`（背景顏色） | CSS 屬性名稱，不翻；課文寫「用來設定背景顏色」 |
| padding | 內距 | `padding`（內距） | CSS 屬性名稱，不翻；課文寫「也就是邊框跟裡面文字之間的留白空間」 |
| px | 像素 | `px`（像素） | CSS 的長度單位，例如 `24px`；課文寫「`px` 是像素（網頁上用來量距離的基本小單位）」 |
| event | 事件 | 事件（event） | 使用者在網頁上做的動作，例如按下按鈕（`click`） |
| function | 函式 | 函式（function） | 第 1 課只用「照著寫就好」帶過 |
| textContent | （不翻） | `textContent` | JavaScript 裡「元素裡面的文字」；課文寫「`textContent` 代表按鈕裡面的文字」 |
| addEventListener | （不翻） | `addEventListener` | JavaScript 的「聽候事件」；第 1 課先照著寫，課文用一句「盯著這顆按鈕，當它發生 `click` 事件時，執行大括號裡的指令」帶過 |
| getElementById | （不翻） | `document.getElementById` | JavaScript 的「依 id 找到元素」；第 1 課先照著看，課文用一句「請瀏覽器去畫面上找出 `id` 叫做 `fav` 的那個按鈕」帶過 |

## 怎麼更新這份表

- 課文整合的人（T-010、T-014、T-016）把新課的術語補進來：每個詞一列，寫出「第一次出現時的寫法」；已經在別課用過的詞，不要換寫法。
- 需要換掉某個詞的寫法時，在討論區提出，由使用者決定；換了之後，所有課文一起改。
- 給 Gemini 的交付包附最新版的這份表（取代「種子術語表」）。
