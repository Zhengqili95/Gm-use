# vibe-learn

免費的 AI 時代學習平台（規劃中）。這個資料夾同時是四個 AI 協作的工作區。

## 怎麼叫每個 AI 開工

開新對話時，資料夾一律選 `D:\02_開發與專案\鳴潮用\vibe-learn`，然後貼上對應的開場白。

**Claude-A（主帳號）**

```
你是 Claude-A。請先讀 AGENTS.md，照「每次開工的步驟」做，然後告訴我你看到什麼、接下來要做什麼。
```

**Claude-B（第二個帳號）**

```
你是 Claude-B。請先讀 AGENTS.md，照「每次開工的步驟」做，然後告訴我你看到什麼、接下來要做什麼。
```

**Codex**

```
你是 Codex。請先讀 AGENTS.md，照「每次開工的步驟」做，然後告訴我你看到什麼、接下來要做什麼。
```

**Gemini（App）**

Gemini 讀不到檔案，第一次要貼完整的背景：

```
你好，我在做一個叫 vibe-learn 的專案：一個免費的 AI 時代學習平台，參考「氛圍學院」的形式（互動練習、個人化學習），但課程內容全部自己做。

團隊成員：
- 我：專案負責人，所有決定由我拍板
- Claude-A、Claude-B：Claude Code，可以直接改專案檔案
- Codex：OpenAI 的 Codex，可以直接改專案檔案
- 你（Gemini）：讀不到專案檔案，我會把討論內容貼給你，再把你的回覆貼回討論區

請你：
1. 意見要具體。可以反對別人，但要說理由，不要只附和。
2. 用下面的格式回覆，方便我直接貼回討論區：

### [M-編號] 日期 時間 · Gemini（使用者轉貼）→ 收件者
**主題**：…
（內容）
**需要回覆**：誰、什麼（沒有就寫「無」）

編號和時間可以留空，我貼回去時會補上。

以下是目前的討論內容：
（在這裡貼上 team/BOARD.md 的最新留言）
```

之後每次要問 Gemini，可以請任何一個 Claude 或 Codex「幫我整理要貼給 Gemini 的內容」。Gemini 回覆後，把回覆貼給它們，請它們照原文記錄到討論區。

## 觀察房：即時看大家在討論什麼

雙擊 `tools/observer/start-observer.cmd`，會跳出一個黑色視窗並自動打開瀏覽器（網址 http://127.0.0.1:5180）。要關掉時，關掉那個黑色視窗就好。

- **上方座位**：每位成員最後什麼時候發言，以及還欠哪幾則留言的回覆。點座位可以只看那位成員的留言。
- **討論區／規格書**：每 2 秒自動更新，有新留言時會亮一下。
- **右側**：任務進度和定案紀錄。

觀察房只能看，不能發言，也不會改任何檔案。

## 檔案在哪裡

| 檔案 | 用途 |
|---|---|
| `AGENTS.md` | 所有 AI 的共同規則 |
| `CLAUDE.md` | Claude 的入口，只負責匯入 `AGENTS.md` |
| `docs/SPEC.md` | 規格書 |
| `team/BOARD.md` | 討論區 |
| `team/TASKS.md` | 任務表 |
| `team/DECISIONS.md` | 定案紀錄 |
| `.claude/skills/`、`.agents/skills/` | Claude 和 Codex 用的 skill（兩份內容相同） |
| `tools/observer/` | 觀察房（只用 Node.js，不需要另外安裝套件） |

`team/` 沒有進 git，只存在這個資料夾裡。要備份的話，直接複製整個 `team/` 資料夾。
